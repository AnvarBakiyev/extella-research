# A custom MCP server on top of the Extella API

2 October 2026. Six tools and about 3.2 KB of definitions, against 44 tools and 33 KB of the standard server on the same set of fields.

- `extella_custom_mcp.py`: the server.
- `custom_mcp_record.py`: the recorded session; secrets and machine names are replaced with `<removed>` before the record is written.
- `custom_mcp_test_offline.py`: tests with a stub instead of the API.
- `custom-mcp-2026-10-02.json`: the record.
