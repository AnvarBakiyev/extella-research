# Restyling one report: Extella against a plain program

3 October 2026. The same change, a new look of one report, was made in two builds of the same application: A on Extella (the report is a program in a presentation language, the look is set by that language's handler) and B, a plain Python program. Each change was made by a new AI assistant that had not seen the code. `journal-ru.md` is the fragment of our work journal (in Russian): files changed, time, tokens and checks.

Both builds changed the look in one place and kept the content of the report. On this one report Extella saved nothing: 93,734 tokens and 2.3 minutes against 81,191 tokens and 1.7 minutes. One run per build, an observation, not an average.
