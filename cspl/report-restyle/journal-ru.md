# Изменение оформления отчёта: Extella и обычная программа

Фрагмент журнала замеров, 3 октября 2026. Одна и та же задача — новое оформление отчёта по сверке двух книг позиций — выполнена в двух вариантах приложения: A собрано на Extella (отчёт описан программой на языке презентаций, оформление задаёт обработчик языка), B — обычная программа на Python. Каждое изменение делал новый ИИ-помощник, не видевший программу раньше. По одному выполнению на вариант: это наблюдение, а не среднее серии.

| | A: Extella | B: standalone |
|---|---|---|
| Токены | 93 734 | 81 191 |
| Время | 2,3 мин | 1,7 мин |
| Вызовов инструментов | 8 | 11 |
| Изменено (руками) | 1 файл: обработчик языка презентаций +21/−9 | 2 файла: настройки оформления +5/−3, код рисования +17/−8 |
| Всего строк | +21 / −9 | +22 / −11 |
| Описание отчёта | не менялось и не пересохранялось (70 строк на языке презентаций) | функция содержания отчёта не менялась |
| Пересохранено на платформе | регистратор; обработчик презентаций перерегистрирован на A (10 с) | — |
| Пересборка отчёта | один вызов шага отчёта, 10,3 с | 0,23 с |
| Прогонов | 3, все успешные (1 локальный пробный, регистрация, 1 вызов платформы) | 1, успешный |
| Проверка | цвета, горизонтальные диаграммы, Georgia, строка внизу на 37 слайдах; содержание совпало с прежним | то же на 36 слайдах |

В обоих вариантах оформление действительно менялось в одном месте и содержание отчёта не трогалось. В обоих одного набора настроек не хватило: шрифт заголовков, строка внизу и тип диаграммы потребовали дописать код рисования (в A это и есть обработчик, в B — класс рисования).
