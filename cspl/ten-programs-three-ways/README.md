# Ten programs, three ways to add them

2 October 2026. The same ten small Python functions were added as fixed tools of an MCP server (official Python SDK), through a general executor with program storage (`generic_server.py`, about a hundred lines) and through Extella's MCP server. A script made every call; no model drove the servers. Only Extella was run on a second machine.

- `measure3.py`: the measurement script.
- `generic_server.py`: the general executor used as the second baseline.
- `measure3-result-2026-10-02.json`: the final run; `-run1` and `-run2` are two earlier runs the same day.
- `mcp-tools-2026-10-02.json`: the tool list of Extella's MCP server at that date (44 tools).

The numbers and their limits are in section 5 of the article.
